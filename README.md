# DMで届いた住所ばらし

DM・LINE・メールで届いた住所の文を貼ると、郵便番号・名前・住所の部品に分かれ、送り方の入力欄と同じ並びでコピーできるWebページです。100日100プロダクトチャレンジ Day080。

- 送り方: クリックポスト（CSVあり）／Webゆうパックプリント（ゆうパック・ゆうパケット。CSVあり）／ヤマト「宅急便をスマホで送る」（CSVなし。欄ごとにコピー）
- 何人分かを空行で区切って貼ると、まとめて分けられます（1回40人まで）
- 住所が正しいか（実在するか・郵便番号と合っているか）は確かめていません。使う前に目で確認してください
- 貼った文・お届け先の住所は保存も送信もしません。選んだ送り方と、入力したご依頼主の情報だけ、端末のブラウザ（localStorage）に残ります
- 日本郵便・ヤマト運輸とは関係のない個人の道具です。各社の欄の決まりは2026年10月25日に調べたもので、変わることがあります

## ファイル

- `index.html` … 公開するページ（`source/build.py` で組み立てたもの）
- `source/page.html` … 画面
- `source/core.js` … 分け方・欄の決まり・CSV・Shift-JIS の処理
- `source/muni.txt` … 市区町村名の一覧。総務省「全国地方公共団体コード」（令和6年1月1日現在。https://www.soumu.go.jp/main_content/000925835.xlsx ）の都道府県名・市区町村名（政令指定都市の区を含む）。セル内で名前の後ろに読み仮名が続いていた20行は、名前だけにしています
- `source/core-test.js` … 純ロジックの検算（`node source/core-test.js`）

## 組み立て

```
python source/build.py
node source/core-test.js
```
